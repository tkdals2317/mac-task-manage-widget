# Teleport OTP 키 구하는 법

ATM Teleport 탭은 로그인할 때 OTP 6자리를 직접 계산한다. 그래서 휴대폰 OTP 앱에 등록된 **OTP 키(시크릿)** 가 필요하다.
ATM 의 OTP 키 칸에는 아래 셋 중 하나를 넣으면 된다.

- base32 키 문자열 (예: `JBSWY3DPEHPK3PXP`)
- `otpauth://totp/Teleport:<아이디>@<프록시>?secret=<키>&...` 주소
- 위 주소가 담긴 QR 코드 이미지 ("QR 이미지로 읽기")

넣은 뒤 칸 아래 **현재 코드** 6자리가 OTP 앱의 숫자와 같으면 맞게 들어간 것이다.

> OTP 키는 2단계 인증 열쇠다. 채팅·메신저·이슈에 붙여넣지 말고, 내보낸 파일·캡처는 ATM 에 넣은 직후 지운다.

## 어떤 방법을 쓰나

| 지금 OTP 를 어디서 보나 | 방법 |
|---|---|
| 브라우저 확장 (Authenticator 등) | [방법 2](#방법-2-브라우저-확장authenticator에서-꺼내기) 가 가장 빠르다 |
| 휴대폰 앱 (Google OTP / Google Authenticator 등) | [방법 1](#방법-1-tsh-로-otp-기기를-하나-더-등록추천) 추천 |
| 모르겠다 / 위 방법이 안 된다 | [방법 1](#방법-1-tsh-로-otp-기기를-하나-더-등록추천) |

## 방법 1. tsh 로 OTP 기기를 하나 더 등록(추천)

Teleport 에 OTP 기기를 하나 더 등록하면, 그때 **키가 터미널에 글자로 나온다**. 어떤 OTP 앱을 쓰든 되고, 기존 휴대폰 OTP 는 그대로 쓸 수 있다.

1. 먼저 평소처럼 로그인한다 (기존 휴대폰 OTP 사용). 이미 로그인돼 있으면 건너뛴다.

   ```bash
   tsh login --proxy <프록시 주소> --user <Teleport 아이디>
   ```

2. 새 OTP 기기를 추가한다. 이름은 아무거나 (예: `atm`).

   ```bash
   tsh mfa add --type=TOTP --name=atm
   ```

3. 기존 기기로 한 번 더 확인하라는 프롬프트가 나오면 **휴대폰 OTP 앱의 현재 코드**를 넣는다.
4. QR 이미지 창이 열리고 터미널에 다음 항목이 출력된다.
   - `URL: otpauth://totp/...` ← 이 줄 전체를 복사
   - `Secret key: XXXX...` ← 또는 이 키만 복사
5. 복사한 값을 **ATM > Teleport > OTP 키** 칸에 붙여넣는다. 칸 아래에 **현재 코드** 6자리가 나온다.
6. 터미널이 `Once created, enter an OTP code generated by the app` 라고 물으면, ATM 에 보이는 **현재 코드**를 입력한다. `MFA device "atm" added.` 가 나오면 끝이다.
7. (선택) 같은 QR 을 휴대폰 OTP 앱으로도 스캔해 두면, 휴대폰에서도 이 기기의 코드를 볼 수 있다.

참고
- 등록된 기기 목록: `tsh mfa ls` / 잘못 만든 기기 삭제: `tsh mfa rm atm`
- 기존 휴대폰 OTP 기기는 지워지지 않는다. 둘 다 로그인에 쓸 수 있다.
- 6번 전에 터미널을 닫으면 등록되지 않는다. 처음부터 다시 한다.

## 방법 2. 브라우저 확장(Authenticator)에서 꺼내기

웨일·크롬의 **Authenticator** 확장(authenticator.cc)에 Teleport 를 등록해 쓰고 있다면, 백업 파일에서 키를 꺼낼 수 있다.

1. 브라우저 툴바에서 Authenticator 확장 아이콘을 누른다.
2. 확장 창의 **설정(톱니바퀴) > 백업** 으로 간다.
3. **백업 파일 다운로드**(암호화하지 않은 백업)를 누른다. `.json` 또는 `.txt` 파일이 받아진다.
   - "비밀번호로 보호된 백업"이 아니라 **암호화하지 않은 백업**을 받아야 키가 보인다.
4. 받은 파일을 텍스트 편집기로 열고 Teleport 항목을 찾는다.
   - `otpauth://totp/Teleport...` 로 시작하는 줄이 있으면 그 줄 전체를,
   - JSON 에 `"secret": "..."` 형태로 있으면 그 값을 복사한다.
5. ATM 의 **OTP 키** 칸에 붙여넣고, **현재 코드** 가 확장에 보이는 코드와 같은지 확인한다.
6. **백업 파일을 바로 지운다** (휴지통도 비운다).

확장 버전에 따라 메뉴 이름이 조금 다를 수 있다. 백업 메뉴를 못 찾으면 방법 1 을 쓴다.

## 방법 3. 휴대폰 Google OTP(Google Authenticator) 앱

Google OTP 앱의 **코드 이전(Transfer codes) > 코드 내보내기(Export codes)** 는 QR 을 보여주지만, 이 QR 은 일반 `otpauth://` 가 아니라 Google 전용 형식(`otpauth-migration://`)이다.
**ATM 은 아직 이 형식을 읽지 못한다.** 또 내보내기 화면은 캡처가 막혀 있는 경우가 많다.

그래서 휴대폰 Google OTP 사용자는 **방법 1** 을 쓴다. 휴대폰 OTP 는 그대로 두고 ATM 용 기기를 하나 더 만드는 방식이라 가장 간단하다.

| 다른 앱 | 키 꺼내기 |
|---|---|
| Microsoft Authenticator, Authy | 키 내보내기를 지원하지 않는 것으로 알려져 있다 → 방법 1 |
| 2FAS, Aegis | otpauth 주소 내보내기 기능이 있는 것으로 알려져 있다. 안 되면 방법 1 |

## 문제 해결

- **현재 코드가 OTP 앱과 다르다**: 키를 잘못 복사했다 (앞뒤 공백·줄바꿈, 다른 계정의 키). Mac 시계가 자동 맞춤인지도 확인한다 (시스템 설정 > 일반 > 날짜 및 시간).
- **`ERROR: invalid username, password or second factor`**: 사용자 ID 가 Teleport 아이디인지(`developer` 아님), 비밀번호, OTP 키를 확인한다.
- **"otpauth://totp QR 이 아니에요"**: Google OTP 내보내기 QR 이다. 방법 1 을 쓴다.
