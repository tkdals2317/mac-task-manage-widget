# ATM (Ats Task Manager)

macOS 메뉴바 상주 플로팅 위젯. 할 일(마감일) + 내 Jira 미완료 이슈 + Claude Code 세션 기반 하루 업무 요약.

## 설치 (팀원용)

### 준비물

- macOS 14 이상
- Xcode 명령줄 도구 (이미 있으면 생략)

```bash
xcode-select --install
```

```bash
swift --version
```

- 저장소 접근 권한: 비공개 GitHub 저장소라 관리자에게 초대를 요청한다.
- 요약 기능을 쓰려면 Claude Code CLI 로그인 상태여야 한다.

```bash
claude --version
```

### 설치

1. 저장소를 받는다.

```bash
git clone https://github.com/tkdals2317/mac-task-manage-widget.git
```

```bash
cd mac-task-manage-widget
```

2. 설치하고 실행한다.

```bash
make install
```

```bash
open ~/Applications/ATM.app
```

### 처음 설정

메뉴바/Dock 아이콘 → 패널 맨 아래 ⚙(설정).

1. **Jira**: 이메일 입력, "토큰 발급 ↗"로 API 토큰을 만들어 붙여넣고 저장 → 연결 테스트. 키체인 창이 뜨면 **항상 허용**.
2. **Claude 연동**: "활동 훅 설치", "/worklog 스킬 설치". 훅은 새 Claude Code 세션부터 기록한다.
3. **창·일반**: "로그인 시 실행" 켜기.
4. **요약**: 생성 시각 확인 (기본 18:00).

### 업데이트

앱 **설정 > 정보 > 업데이트 확인**에서 새 커밋을 확인하고 **업데이트** 버튼 한 번으로 갱신한다 (`git pull --ff-only` + `make install`, 끝나면 앱이 다시 열림). 새 버전이 있으면 패널 하단에 "업데이트 있음 (N)"이 뜬다. 소스 폴더에 커밋하지 않은 수정이 있으면 업데이트가 거부된다. 실패 로그는 `~/Library/Application Support/TaskWidget/logs/update.log`.

수동으로 하려면:

```bash
git pull
```

```bash
make install
```

업데이트(재설치)할 때마다 처음 Jira를 불러올 때 키체인 창이 한 번 뜬다. **항상 허용**을 누르면 그 버전에서는 다시 묻지 않는다. 창이 떠 있어도 앱은 멈추지 않는다.

### 문제 해결

- 패널이 안 보임: 메뉴바 아이콘 클릭 (Dock 아이콘 클릭도 가능).
- Jira 401: 토큰을 다시 발급해 저장.
- 요약 실패 `claudeNotFound`: 터미널에서 `command -v claude` 로 경로를 확인해 설정 > 요약 > claude 경로에 입력 (또는 **자동 찾기**).
- 요약이 "기록 없음": 활동 훅이 설치됐는지, 훅 설치 이후의 새 세션인지 확인.
- 키체인 창이 앱을 켤 때마다 뜸: "허용" 대신 **항상 허용**을 눌렀는지 확인. (재설치 직후 한 번 뜨는 건 정상 — Apple 개발자 팀 ID 없이 빌드한 앱이라 macOS가 새 버전마다 다시 묻는다.)
- 삭제: 먼저 설정 > Claude 연동에서 훅·스킬을 제거한 뒤, 앱(`~/Applications/ATM.app`)을 휴지통으로, 데이터 폴더 `~/Library/Application Support/TaskWidget/` 를 삭제.

### 참고

- 이전 이름(TaskWidget.app)에서 업그레이드하면 설정 > Claude 연동에서 활동 훅을 **재설치**(경로 변경)하고, 로그인 시 실행을 껐다 켠다.
- Dock 아이콘 클릭 = 패널 다시 보이기.
- `make app` 은 로그인 키체인의 "TaskWidget Dev" 인증서로 자동 서명한다. 없으면 ad-hoc 서명.

## 사용

- 할 일: 입력 후 Enter. 📅/배지 클릭으로 마감 설정. 지난 마감 빨강, 오늘 주황. 제목 더블클릭 → 바로 수정 (Enter 저장, Esc 취소).
- 태그: 태그는 그룹에 속하고, 그룹마다 "하나만"(같은 그룹 태그는 하나만 붙음) 또는 "여러 개" 선택. 할 일 오른쪽의 태그 영역(없으면 호버 시 "＋태그") 클릭 또는 우클릭 메뉴(그룹별 하위 메뉴)로 토글. 행에는 그룹 순서 → 태그 순서대로 최대 2개 + "+N". 설정 > 태그에서 그룹/태그 추가·삭제·이름·드래그 순서, 색 직접 지정(색 점 클릭: 프리셋 8색 + 색상 선택), 기본값 복원. "태그 순서로 정렬"(기본 켜짐)이면 "정렬 기준" 그룹의 태그 순서 → 마감 → 생성 순(그 그룹 태그가 없는 할 일은 뒤). 기존 태그는 "중요도" 그룹(하나만)으로 자동 이전.
- 노란 버튼 = Dock으로 최소화.
- 설정 > 창·일반 > 탭에서 할 일/요약 탭을 켜고 끌 수 있음 (하나만 켜면 탭 바가 숨겨짐).
- Jira: 내게 할당된 미완료 이슈. 클릭하면 브라우저. 설정에서 JQL 교체 가능.
- Jira 수정 버전: 이슈 행 오른쪽에 회색 버전 태그(공통 접두어 NMRS_ 는 숨김), 헤더의 "버전 전체" pill 로 버전별 필터(× 로 해제), 메뉴의 "버전별로 묶기"로 버전 그룹 표시. 선택은 재실행 후에도 유지.
- 요약: 매일 설정 시각(기본 18:00)에 자동 생성. Claude Code 세션에서 `/worklog` 로 일지를 남기면 그게 1급 입력, 훅이 모은 대화 기록은 보완.
- 요약은 `claude -p` 로 생성 (Claude Code CLI 구독 사용).
- 설정 > 정보: 버전·빌드 확인, 업데이트 확인 및 원클릭 업데이트 (6시간마다 자동 확인).
- 설정 > 요약에서 요약 프롬프트 지시문 편집, `{날짜}` 치환, 데이터는 자동 첨부.

## 개발

```bash
make build   # swift build
make test    # swift test (Core 단위 테스트)
make run     # build/ATM.app 실행
```

앱 아이콘: `swift scripts/make-icon.swift` 로 다시 생성 (Resources/AppIcon.icns)

앱을 옮기면 `~/.claude/settings.json` 의 훅 경로가 깨진다. 설정 > Claude 연동에서 "재설치".

## 수동 확인 체크리스트

하나씩 확인 후 체크.

- [ ] 메뉴바 아이콘 + Dock 아이콘. 좌클릭 토글, 우클릭 메뉴 4개
- [ ] 패널 닫기(빨강) 후 Dock 아이콘 클릭 → 패널 다시 표시
- [ ] 노란 버튼 → Dock으로 최소화, Dock 아이콘/메뉴바 아이콘 클릭 → 복원
- [ ] 패널이 Finder/브라우저/터미널 위에 떠 있음. 전체화면 앱 위에서도 보임 (allSpaces on)
- [ ] 할 일 추가/완료/삭제/마감/비우기, 재실행 후 유지
- [ ] 할 일 제목 더블클릭 → 인라인 편집, Enter 저장 / Esc 취소 / 다른 곳 클릭 시 저장, 공백만 입력하면 원래 제목 유지
- [ ] 태그: 설정 > 태그에서 태그 추가(새 태그 포커스)/이름 변경(빈 값 복원)/삭제/그룹 안 드래그 순서/기본값 복원(확인창). 할 일 행에서 팝오버(그룹 섹션, "중요도 · 하나만")·우클릭 그룹별 하위 메뉴로 토글(팝오버 유지), 최대 2개 + "+N", 없으면 호버 시 "＋태그"
- [ ] 태그 그룹: 그룹 추가/이름/위·아래 이동/삭제(확인창: 태그 N개), 하나만 그룹은 다른 태그 선택 시 교체, 여러 개 → 하나만 전환 시 첫 태그만 유지, "정렬 기준" 그룹 지정. 색 점 클릭 → 프리셋 8색 + 색상 선택기로 임의 색, 행 캡슐에 반영
- [ ] "태그 순서로 정렬" 켜면 정렬 기준 그룹의 태그 순 → 마감 순, 끄면 마감 순. 태그 삭제 시 할 일은 남고 태그만 제거. 완료 항목도 태그 유지(흐리게)
- [ ] Jira 목록, 클릭 시 브라우저, ↻, 토큰 오류 메시지, JQL 커스텀
- [ ] Jira 버전 pill: 행에 버전 태그, 메뉴 개수·최신순, 버전 선택 시 강조 pill + × 해제 + 태그 숨김, 없는 버전이면 "이 버전의 미완료 이슈 없음", 버전별로 묶기(상태 표시), 재실행 후 유지
- [ ] 설정 > 창·일반 > 탭: 하나 끄면 탭 바 숨김·남은 탭만 표시, 마지막 하나는 비활성, 다시 켜면 탭 바 복귀
- [ ] 설정 각 항목 즉시 반영 (투명도, 호버, 테마, 글자 크기, 항상 위, Spaces)
- [ ] 훅 설치 후 Claude Code 세션 → activity.jsonl 증가. 요약 생성용 claude -p 세션은 기록 안 됨 (cwd = 데이터 폴더)
- [ ] `/worklog` 스킬 → worklog 파일 append → 요약 탭 즉시 표시
- [ ] 예정 시각 자동 생성 + 알림. 재실행/깨우기 catch-up. 수동 "다시 생성"
- [ ] 첫 실행 시 알림 권한 요청 (이미 요청됐을 수 있음 → 시스템 설정 > 알림 > ATM 확인)
- [ ] 생성 시각을 과거로 바꾸고 오늘 파일이 없으면 ~3초 후 즉시 생성
- [ ] 오늘 파일이 있으면 시각을 바꿔도 재생성 안 함
- [ ] 지시문 바꾸고 요약 탭 '다시 생성' → 바뀐 형식으로 나옴
- [ ] 최근 날짜의 summaries 파일 하나 지우고(그날 activity 있음) 재실행 → 그날 요약 자동 생성
- [ ] 메뉴바 우클릭 "요약 지금 생성" → 패널 표시 + 요약 탭 + 강제 재생성
- [ ] 요약 실패 시 "요약 실패: {이유}" 알림
- [ ] 잠자기 → 깨우기 (예정 시각 지남, 오늘 파일 없음) → 생성
- [ ] 기록 없는 날 → "오늘 기록 없음" 파일
- [ ] 로그인 시 실행 토글 → 시스템 설정 로그인 항목에 표시
- [ ] 설정 시트 텍스트 필드에서 ⌘V 붙여넣기 / ⌘A 모두 선택 동작. API 토큰 필드는 SecureField 라 한글 입력소스에서는 글자가 안 들어감 → ABC 로 전환해서 붙여넣기
- [ ] 설정 > 정보: 버전/빌드 날짜/소스 폴더 표시, "업데이트 확인" → "최신 버전입니다" 또는 새 커밋 목록, 새 커밋이 있으면 패널 하단 "업데이트 있음 (N)" → 클릭 시 정보 섹션 열림
- [ ] 업데이트 버튼 → "업데이트 중…" 후 앱이 재시작되고 버전의 빌드 번호가 올라감. 소스 폴더에 수정이 있으면 거부 메시지 + 실패 시 "로그 열기"
- [ ] 앱 종료 후 재실행 시 패널 위치/크기/탭/섹션 접힘 유지

화면 확인이 필요해 자동 검증하지 못한 UI 항목:

- [ ] 메뉴바 아이콘 표시, 좌클릭 시 패널 토글
- [ ] 우클릭 메뉴 4개: 패널 토글, 요약 지금 생성, 설정…, 종료
- [ ] 할 일 입력, 마감 팝오버의 버튼(오늘/내일/다음 주 월/마감 없음), 달력 클릭 시 팝오버 유지
- [ ] Jira 목록 표시, 이슈 클릭 시 브라우저 열림
- [ ] 요약 탭: 날짜 이동, 복사, 생성
- [ ] 설정 시트에서 텍스트 필드 입력 가능
- [ ] 투명도/호버/테마/글자 크기 변경이 즉시 반영
- [ ] 닫기 버튼으로 숨긴 뒤 다시 표시해도 투명도 유지
- [ ] Claude Code 세션 하나 끝낸 뒤 `activity.jsonl`에 `"event":"prompt"` 와 `"event":"stop"` 줄이 둘 다 있음
- [ ] 재설치 후 키체인 프롬프트가 다시 뜨지 않음 (TaskWidget Dev 인증서 사용 시) / 프롬프트가 떠 있어도 할 일·요약 UI 는 멈추지 않음
- [ ] `make install` 후 첫 Jira 갱신 때 키체인 프롬프트가 뜨면 **항상 허용** 선택 (허용만 누르면 매 갱신마다 다시 뜸)
