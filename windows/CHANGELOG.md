# Windows 판 업데이트 노트

새 버전을 올릴 때는 `package.json` 의 `version` 을 올리고 맨 위에 `## <버전> — <날짜>` 섹션을 추가한다.
main 에 들어가면 CI 가 `windows-v<버전>` 릴리스를 만들고 설치 파일을 붙인다. 앱의 업데이트 확인은 이 릴리스를 본다.

## 0.3.0 — 2026-11-20

- **E2E 탭**이 들어왔어요 (Mac 판 1.24.0). Jira 이슈를 고르고 환경(DV/ST/ST2)을 골라 "검증 실행"을 누르면, 내 Aside 브라우저가 이슈를 읽고 테스트 환경에서 직접 동작을 확인해 PASS/FAIL/BLOCKED/SKIPPED 와 시나리오별 실제 결과·스크린샷을 남겨요. 한 번에 하나씩 돌고, 실행 중에 누르면 대기열에 쌓여요. 취소·제한 시간도 있어요. 업데이트하면 탭이 한 번 켜져요 (설정 > 창 · 일반 > 탭에서 끌 수 있어요).
- 이슈 내용은 ATM 이 Jira 토큰으로 받아 Aside 에 넘겨요 (설명·댓글·연결 이슈·PR 링크·첨부 이미지). 실행 버튼 옆에서 모델을 고를 수 있고, 실패·취소된 검증은 이력 옆 ↻ 로, 끝난 검증은 결과 화면의 "다시 실행"으로 다시 돌려요.
- 안전하게 돌아요: Aside 는 guard 권한으로 실행하고, Aside 계정 폴더 아래 실행용 폴더에서만 파일을 읽고 써요. 끝나면 ATM 이 result.json 과 스크린샷 이미지만 골라 가져와요. 테스트 계정 비밀번호는 넘기지 않고, 설정 > E2E 의 주소 옆 "Aside 에서 열기"로 직접 로그인해 Aside Vault 에 저장해 두면 Aside 가 자동 채우기로 로그인해요. PR(운영) 환경은 기본으로 꺼져 있고, 켜도 조회만 하라고 지시하며 실행 전에 한 번 더 물어요. 결과 화면은 ATM 이 만든 Jira 링크와 결과 폴더 안의 이미지만 열어요.
- 로그인에 막히면 결과 화면 맨 위에 이유(Vault 를 아직 안 만듦 · Vault 잠김 · 저장된 로그인 없음 · 저장된 계정이 다름 · 사이트가 거절함 · 2단계 인증 · 그 밖)와 할 일이 뜨고, 로그인 페이지를 Aside 에서 바로 열어 다시 실행할 수 있어요. 검증을 돌리지 못했을 때(CLI 가 오래됨 · 로그인이 풀림 · 창이 닫힘 등)도 이유와 할 일, 해결 버튼이 같이 떠요.
- E2E 탭 위쪽·설정 > E2E·설정 도우미에 "준비" 목록이 떠요. Aside 브라우저 → Aside CLI → Aside 계정 → Aside 창 → 환경 주소 → 환경 로그인 순서로 확인하고, 막힌 줄에 해결 버튼(Aside 다운로드 · 터미널에서 업데이트 · 터미널에서 로그인 · Aside 열기 · 설정 열기 · Aside 에서 열기)이 붙어요. 터미널 버튼은 PowerShell 창에서 `aside update` / `aside login` 을 돌려요.
- 결과 화면의 "내보내기"는 결과를 HTML 파일 하나(스크린샷 포함)로 바탕 화면에 저장해요. "Jira 댓글로 남기기"는 판정·가정·시나리오를 Jira 댓글로 달고, "댓글 + 스크린샷"을 고르면 스크린샷을 이슈에 첨부해 댓글 안에 이미지로 보여줘요. 이력에서도 말풍선·↗ 버튼으로 바로 댓글을 남기거나 Jira 이슈를 열어요.
- 할 일 탭 Jira 목록에 최근 검증 판정 뱃지가 붙고, 누르면 결과로 가요. 탭 바꾸기 단축키는 `Ctrl + 1~6` 이에요.
- 아직 Windows 에서 확인하지 못한 것: Aside 브라우저·CLI 의 설치 위치와 `%USERPROFILE%\.aside` 폴더 구조(자동으로 못 찾으면 설정 > E2E 에서 aside 경로를 직접 넣어 주세요), "Aside 에서 열기"가 쓰는 Aside 브라우저 실행 파일 위치.

- 패널 위치·크기를 기억해서 다시 켜면 마지막 자리에 열려요 (모니터를 뺐으면 처음 자리).

## 0.2.0 — 2026-11-13

- Mac 판의 나머지 기능이 모두 들어왔어요.
  - **요약 탭:** Claude Code 세션·업무 일지·커밋으로 하루·주간 요약을 만들어요. 정한 시각(기본 18:00)에 자동으로 만들고, 꺼져 있던 날은 최근 7일까지 채워요. 직접 수정·복사·다시 생성·일지 열기.
  - **Claude 연동:** 활동 훅, /worklog 스킬, 할 일 추가 스킬(atm-todo). `atm.exe --hook`, `atm.exe --add-todo` 를 지원해요.
  - **PR 탭:** GitHub(gh 로그인)·Bitbucket(API 토큰)의 리뷰 요청과 내 PR, 상태·저장소·사람 필터, 바로 승인, 새 리뷰 요청·승인·변경 요청·댓글 알림, 할 일로 보내기.
  - **Teleport 탭:** 비밀번호·OTP 자동 입력 로그인, DB·앱 터널 켜고 끄기, 자동 유지(재로그인·재연결, 간격을 늘려 계속 시도), 시작 시 자동 재연결.
  - **설정 도우미**, 설정 > 정보 > **진단 정보 내보내기**, 비밀 정보 저장 위치(자격 증명 관리자 / 파일).
- 모양을 Mac 판에 맞췄어요: 둥근 패널과 신호등 버튼, macOS 식 탭 바·스위치·세그먼트·알약 버튼, Apple SD Gothic Neo 와 닮은 Pretendard 글꼴, 아이콘이 있는 설정 목록. 투명도는 뒤가 비쳐 보이게 바뀌었어요.
- 노란 버튼으로 최소화한 패널은 작업 표시줄에 보이고, 앱을 다시 실행하거나 트레이·단축키로 열면 되살아나요 (전에는 최소화한 패널을 다시 열 수 없었어요).
- 설정 창이 패널이 있는 모니터 가운데에, 다 그려진 뒤에 떠요.
- 개발 실행(`tauri dev`)이 시작 프로그램에 임시 빌드를 등록하거나 설치한 앱의 데이터를 건드리지 않아요.

## 0.1.1 — 2026-11-12

- 설정 창이 빈 화면으로 뜨고, 패널 숨기기·설정 창 닫기·트레이 "종료"가 안 되던 문제를 고쳤어요.
- 기본 단축키를 Ctrl+Alt+Q 로 바꿨어요 (Ctrl+Alt+Space 는 Claude 데스크톱 앱과 겹쳐요). 다른 앱이 쓰는 조합이라 등록이 안 되면 패널 위와 설정 > 창 에 알려줘요.
- 설정 창이 패널에 가려지지 않게 항상 위로 떠요.

## 0.1.0 — 2026-11-12

- Windows 판 첫 버전. 화면 위에 떠 있는 패널, 작업 표시줄 트레이 아이콘(왼쪽 클릭 열고 닫기, 오른쪽 클릭 메뉴), 전역 단축키(기본 Ctrl+Alt+Space), 로그인 시 자동 실행.
- 할 일 탭: 내 할 일(하위 할 일·메모·마감일·태그)과 Jira 목록(상태 바꾸기, 버전 필터·버전별 묶기).
- 노트 탭: 메모(고정·잠금, Windows Hello 로 열기)와 링크(Confluence 별표 포함).
- 설정 창: 창·모양(테마 프리셋, 글자 크기, 투명도), Jira, 노트, 탭, 단축키, 정보·업데이트 확인.
- 비밀값(Jira 토큰 등)은 Windows 자격 증명 관리자에 저장해요.
