# Windows 판 업데이트 노트

새 버전을 올릴 때는 `package.json` 의 `version` 을 올리고 맨 위에 `## <버전> — <날짜>` 섹션을 추가한다.
main 에 들어가면 CI 가 `windows-v<버전>` 릴리스를 만들고 설치 파일을 붙인다. 앱의 업데이트 확인은 이 릴리스를 본다.

## 0.2.0 — 2026-11-13

- Mac 판의 나머지 기능이 모두 들어왔어요.
  - **요약 탭:** Claude Code 세션·업무 일지·커밋으로 하루·주간 요약을 만들어요. 정한 시각(기본 18:00)에 자동으로 만들고, 꺼져 있던 날은 최근 7일까지 채워요. 직접 수정·복사·다시 생성·일지 열기.
  - **Claude 연동:** 활동 훅, /worklog 스킬, 할 일 추가 스킬(atm-todo). `atm.exe --hook`, `atm.exe --add-todo` 를 지원해요.
  - **PR 탭:** GitHub(gh 로그인)·Bitbucket(API 토큰)의 리뷰 요청과 내 PR, 상태·저장소·사람 필터, 바로 승인, 새 리뷰 요청·승인·변경 요청·댓글 알림, 할 일로 보내기.
  - **Teleport 탭:** 비밀번호·OTP 자동 입력 로그인, DB·앱 터널 켜고 끄기, 자동 유지(재로그인·재연결, 간격을 늘려 계속 시도), 시작 시 자동 재연결.
  - **설정 도우미**, 설정 > 정보 > **진단 정보 내보내기**, 비밀 정보 저장 위치(자격 증명 관리자 / 파일).
- 모양을 Mac 판에 맞췄어요: 둥근 패널과 신호등 버튼, macOS 식 탭 바·스위치·세그먼트·알약 버튼, Apple SD Gothic Neo 와 닮은 Pretendard 글꼴, 아이콘이 있는 설정 목록. 투명도는 뒤가 비쳐 보이게 바뀌었어요.
- 노란 버튼으로 최소화한 패널은 작업 표시줄에 보이고, 앱을 다시 실행하거나 트레이·단축키로 열면 되살아나요 (전에는 최소화한 패널을 다시 열 수 없었어요).
- 설정 창이 패널이 있는 모니터 가운데에, 다 그려진 뒤에 떠요.
- 개발 실행(`tauri dev`)이 시작 프로그램에 임시 빌드를 등록하거나 설치한 앱의 데이터를 건드리지 않아요.

## 0.1.1 — 2026-11-12

- 설정 창이 빈 화면으로 뜨고, 패널 숨기기·설정 창 닫기·트레이 "종료"가 안 되던 문제를 고쳤어요.
- 기본 단축키를 Ctrl+Alt+Q 로 바꿨어요 (Ctrl+Alt+Space 는 Claude 데스크톱 앱과 겹쳐요). 다른 앱이 쓰는 조합이라 등록이 안 되면 패널 위와 설정 > 창 에 알려줘요.
- 설정 창이 패널에 가려지지 않게 항상 위로 떠요.

## 0.1.0 — 2026-11-12

- Windows 판 첫 버전. 화면 위에 떠 있는 패널, 작업 표시줄 트레이 아이콘(왼쪽 클릭 열고 닫기, 오른쪽 클릭 메뉴), 전역 단축키(기본 Ctrl+Alt+Space), 로그인 시 자동 실행.
- 할 일 탭: 내 할 일(하위 할 일·메모·마감일·태그)과 Jira 목록(상태 바꾸기, 버전 필터·버전별 묶기).
- 노트 탭: 메모(고정·잠금, Windows Hello 로 열기)와 링크(Confluence 별표 포함).
- 설정 창: 창·모양(테마 프리셋, 글자 크기, 투명도), Jira, 노트, 탭, 단축키, 정보·업데이트 확인.
- 비밀값(Jira 토큰 등)은 Windows 자격 증명 관리자에 저장해요.
